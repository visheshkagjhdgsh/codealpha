# Web Template

A minimal, modern, no-build starter you can open directly in the browser.

## Quick start
- Open `index.html` in your browser, or
- Serve locally:
  - Python: `python3 -m http.server 5173` then open `http://localhost:5173`
  - Node: `npx serve@latest -l 5173` then open `http://localhost:5173`

## Customize
- Update colors and spacing in `styles.css` under `:root` variables
- Edit content/sections in `index.html`
- Add behavior in `main.js`

## Structure
```
web-template/
├─ index.html
├─ styles.css
├─ main.js
└─ assets/
   └─ logo.svg
```

## Notes
- Light/dark theme remembers your preference
- Layout is responsive and accessible by default
