# Acme — Modern Starter Website

A responsive, accessible static website you can customize.

## Run locally

- With Python (recommended):
  ```bash
  python3 -m http.server 5173 -d /workspace/website
  ```
  Then open `http://localhost:5173`.

- Or using Node (if installed):
  ```bash
  npx serve /workspace/website --listen 5173 --single --no-clipboard
  ```

## Customize

- Edit `index.html` to change content/sections
- Edit `styles.css` for colors/spacing/typography
- Edit `script.js` for behavior (mobile menu, theme toggle, form)
- Replace `assets/logo.svg` with your own logo
